# Meshtastic Telemetry Dashboard

A small Vercel dashboard for Meshtastic environmental telemetry. The first deployment stores and displays water temperature from the MX2201 -> Chew can -> LoRa -> home gateway path.

The database intentionally stores the complete Meshtastic metrics payload in JSONB, so later non-HOBO sensors (stage, conductivity, soil moisture, rainfall, battery telemetry, etc.) can use the same ingestion path.

## Vercel project

Set the Vercel project Root Directory to:

`telemetry-dashboard`

Required environment variables:

- `DATABASE_URL` - Neon Postgres connection string
- `INGEST_KEY` - long random secret used by the EMQX HTTP action
- `STATION_NAME` - optional friendly label for the current test station

## Database

Run `schema.sql` once against the connected Neon database.

## Ingest endpoint

`POST /api/ingest`

Authentication:

`X-Ingest-Key: <INGEST_KEY>`

The endpoint accepts Meshtastic MQTT JSON generated by firmware 2.7.26. For environmental telemetry it expects:

```json
{
  "type": "telemetry",
  "from": 3257761772,
  "timestamp": 1786591673,
  "payload": {
    "temperature": 6.44
  }
}
```

The temperature value is Celsius, matching Meshtastic environmental telemetry.

## Dashboard

The static dashboard polls `/api/readings` and displays:

- current water temperature
- station freshness/online status
- 24-hour min/max
- temperature history
- RSSI/SNR when available
- recent readings
